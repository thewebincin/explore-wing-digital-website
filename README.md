# Explore Wings Digital Technologies

The public Explore Wings Digital Technologies website is a static site built with HTML, CSS, and JavaScript. It has no admin panel or backend.

## Published website

- [Open the website on GitHub Pages](https://thewebincin.github.io/explore-wing-digital/)
- [Find the studio on Google Maps](https://maps.app.goo.gl/tTpirN3fq4usdxjG7)

## Website pages

- `index.html` — home page
- `services.html` and `services/` — services
- `industries.html` and `industries/` — industries served
- `about.html`, `pricing.html`, `contact.html`, and `process.html`
- `privacy.html` and `terms.html`
- `maintenance.html` — maintenance notice

Styles and client-side behavior are in `css/`, `js/`, and the root-level website assets. Edit the HTML, CSS, or JavaScript files directly to update the public website.

## Preview

Open `index.html` in a browser or serve the project directory with a local HTTP server. The site can be deployed as a static website, including through GitHub Pages.
